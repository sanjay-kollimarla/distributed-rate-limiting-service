Distributed Rate Limiter

A live Redis-backed limiter. Send real requests, watch it say no, then push it with simulated load.

Designed and built by Sanjay Kollimarla

Token bucket

Each client has a bucket that refills at a steady rate. A request spends one token. Bursts are allowed up to the bucket size, then traffic is paced to the refill rate.

Sliding window

Counts requests in the last N seconds, with no reset boundary to game. Used here for POST /api/orders: 10 per minute.

Shared and atomic

State lives in Redis and each check is one Lua script, so any number of app instances share one limit with no race conditions.

2. Load test: many clients at once

Runs in your browser against this server. Each simulated client has its own identity and its own limit, unless you tick “all share one client”. Total load is capped at 500 requests/sec to protect the shared Redis.
